# 3K — Tech & Academic Services

> A personal website for **3K**, a family-driven service business offering tech repairs, tech assistance, and academic support.

## 🌐 Live Site
> _Deploy via GitHub Pages — see setup instructions below._

## 📁 Project Structure

```
3K/
├── index.html      # Main HTML page
├── style.css       # All styles (monochrome theme)
├── script.js       # Interactivity & animations
└── README.md       # This file
```

## 🛠️ Services Featured
- **Tech Repairs** — hardware fixes, OS reinstall, virus removal, optimization
- **Tech Assistance** — software setup, network issues, remote/on-site support
- **Academic Assistance** — research, presentations, proofreading, school projects

## 🚀 Deploy to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **Deploy from a branch → main → / (root)**
4. Your site will be live at `https://<your-username>.github.io/3K/`

## ✏️ Customization Notes
- Update contact info, social links, and pricing once ready
- Replace the form with [Formspree](https://formspree.io/) or [EmailJS](https://www.emailjs.com/) for real email delivery
- Add a `favicon.ico` for browser tab branding
